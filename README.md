# AI Agent Memory

Система долговременной памяти для управления ИИ-агентами.

## Назначение проекта

Разработка серверной системы, обеспечивающей хранение, извлечение и управление долговременной памятью ИИ-агентов с изоляцией данных по проектам.

## Архитектура

Проект разрабатывается на основе микросервисной архитектуры.

Основные компоненты:

- `user-project-service` — управление пользователями и проектами.
- `embedding-service` — создание векторных представлений.
- `anonymization-service` — обезличивание данных.
- `conversation-memory-service` — работа с историей диалогов и памятью.
- `search-warmup-service` — поиск и подготовка контекста.
- `platform-service` — платформенные операции и взаимодействие компонентов.
- `gateway` — API Gateway.
- `mcp-server` — интеграция с ИИ-агентами через MCP.
- `admin-web` — веб-интерфейс администратора.
- `developer-web` — веб-интерфейс разработчика.

## Инфраструктура

- PostgreSQL — хранение структурированных данных.
- Qdrant — векторное хранилище.
- Kafka — асинхронный обмен сообщениями.
- MinIO — объектное хранилище.

## Структура репозитория

- `services/` — backend-микросервисы.
- `gateway/` — API Gateway.
- `mcp-server/` — MCP Server.
- `admin-web/` — интерфейс администратора.
- `developer-web/` — интерфейс разработчика.
- `infrastructure/` — конфигурация инфраструктуры.
- `docs/` — документация проекта.
- `scripts/` — вспомогательные скрипты.
